# Local library provenance

The library is bundled so the project opens without machine-specific paths.

| Assets | Source and licence | Local changes |
| --- | --- | --- |
| Standard passive, connector, power and mechanical symbols | KiCad community libraries, CC-BY-SA-4.0 with KiCad library exception | Selected into `Picolino.kicad_sym`; other IC symbols are authored from verified pin maps. |
| Standard footprints and associated STEP models | KiCad 10 library installation, CC-BY-SA-4.0 with KiCad library exception | Project-relative model paths. DIP sockets show a separate chip model. Crystal pads enlarged to 1.2 mm with 0.7 mm drills for formed AB38T leads. Trimmer pads adapted to the KKT330TR land pattern. |
| `Pico2_Socketed` | KiCad `Module:RaspberryPi_Pico_Common_THT`, same library licence | Common pad geometry retained; antenna notes removed; Pico 2 model and socket model added. |
| `rpi_pico2.step` | Raspberry Pi Ltd, MIT, official Pico 2 design files | Translation to the footprint's pad-1 origin and socket height only. |
| `W5100S_Cyboard` | Cyboard EAGLE `W5100S-NETWORK-MODULE`, GPL-3.0-or-later | Pad coordinates translated to KiCad; courtyard, labels and original simplified envelope model added. |
| `w5100s-envelope.wrl` | Picolino, GPL-3.0-or-later | Generated by `tools/module_model.py`; visual envelope only, not a manufacturer fit model. |

Footprint upstream names and input SHA-256 hashes are recorded in
[`footprint-sources.json`](footprint-sources.json). Standard models retain their
original embedded author/licence metadata. Symbols selected from upstream are:
`Device:{R,C,C_Polarized,C_Trim,Crystal,D,D_Schottky,LED,Battery_Cell,Polyfuse}`,
`Connector_Generic:{Conn_01x02,Conn_01x03,Conn_02x02_Odd_Even}`,
`Mechanical:MountingHole`, `Connector:TestPoint`, and `power:PWR_FLAG`.

Read [KiCad's library licence](KiCad-LICENSE.md) and
[the Pico model MIT notice](3dmodels/Pico2-LICENSE.txt). The library exception
allows designs to use the data under their own licence; the copied library
collection retains the upstream terms.

The CV1 model uses the TZC3 mechanical envelope for the selected Kingtronics
KKT330TR. Its colour and fine details are illustrative. The crystal model is a
nominal 3 × 8 mm can; allow the AB38T maximum 3.2 × 8.3 mm body.
